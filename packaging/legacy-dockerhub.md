# Icey has moved

Current library images are published at **ghcr.io/auscaster/icey**:

```bash
docker pull ghcr.io/auscaster/icey:latest
```

For the runnable media server:

```bash
docker run --rm --network host ghcr.io/auscaster/icey-server:latest
```

Existing Docker Hub tags remain available. New releases use the auscaster images above.

- [Project homepage](https://auscaster.com/icey)
- [Source and releases](https://github.com/auscaster/icey)
